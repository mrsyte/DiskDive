DiskDive

See what's using space. Nothing is ever deleted.

Analyze a folder

Pick a personal folder — Downloads, Documents, a project directory — and DiskDive maps what's taking up room.

  • Read-only. DiskDive never deletes, moves, or edits files.
  • Suggestions only. It flags files that are both at least 30 days old and haven't been opened in 30+ days — for you to review.
  • Protected files are never flagged. Keys, credentials, .env, configs, source manifests, and anything under system folders are left out.

System directories (/System, /Library, Program Files, …) can't be scanned.
